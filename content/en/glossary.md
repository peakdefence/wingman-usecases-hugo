---
title: Glossary
description: The words this site and WINGMAN use, in plain language.
layout: single
type: glossary
terms:
- t: Project
  d: An organisation's own workspace in WINGMAN. A consultant works in one project per client, and an assistant's connection can be restricted to a single project.
- t: Suggestion
  d: One proposed change to the records, such as a field, a link or a new record, with a description of what changes and why. It takes effect only when a person accepts it.
- t: Ask Wingman
  d: The assistant built into WINGMAN. It opens beside any record and offers skills for that kind of work.
- t: Brief
  d: A short summary of a record that WINGMAN's AI writes from the record and refreshes when it changes. The history keeps which model wrote it.
- t: History
  d: Every change to a record, with what changed, the value before and after, when and who made it. The time is set by the system, and the history cannot be edited or deleted.
---
